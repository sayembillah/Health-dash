# 🌿 HealthDash – Your Personalized Wellness Dashboard

**HealthDash** is a modern, intuitive web app that helps users monitor and understand key health metrics based on their age, weight, and height. From daily water intake to ideal weight ranges and sleep recommendations, HealthHub offers scientifically backed and age-appropriate insights — all in one place.

---

## 🚀 Features

- 🧠 **Age-Based Tips**  
  Get smart, science-backed health advice tailored to your age group.

- ⚖️ **Ideal Weight Range**  
  Understand your healthy weight boundaries using accurate BMI calculations.

- 💧 **Water Intake Recommendation**  
  Learn how much water you need daily in liters *and* glasses, based on your weight.

- 😴 **Sleep Recommendation**  
  Discover the optimal sleep hours for your age bracket.

- 📊 **More Features**
  - Macronutrient breakdown (carbs, proteins, fats)
  - BMR (Basal Metabolic Rate) calculator
  - Caloric needs by activity level

---

## 🛠️ Tech Stack

- **Frontend**: React.js  
- **Styling**: Tailwind CSS  
- **State Management**: React Context API  

---

## 📦 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/your-username/health-dash.git
cd healthhub
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

---

### Sample User Input (for demo/testing):
```json
{
  "height": "5.6",  // in feet.inches format
  "weight": 65,     // in kilograms
  "age": 24         // in years
}
```
